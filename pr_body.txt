This PR resolves two major frontend issues:

### 1. Fixes #46 (UI Polish)
- Overhauled the UI from the tactical layout to a warm, "Humanistic Marine" design.
- Implemented a seamless Dark / Light mode toggle utilizing CSS variables.
- Redesigned the loading splash screen with the animated ORCA SVG logo, custom Inter fonts, and perfect dark mode support.

### 2. Fixes #40 (Multi-turn conversation history UI)
- Implemented hybrid session persistence. The UI securely saves the rich chat history (AI responses, traces, verdicts) in `localStorage`.
- Wired the frontend to `GET /api/v1/session/{id}/history`. On reload, if the backend recognizes the session, the UI flawlessly restores the chat and context. If not, it gracefully creates a new one without looping.
- Added a "New Chat" button to cleanly clear local storage and start a fresh session context.
- Added robust mobile optimizations (dedicated Map/Chat toggle button, hiding redundant headers, and fixing Leaflet map rendering glitches on display toggle).
